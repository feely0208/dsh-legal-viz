# 诉讼可视化（DSH 插件）

把案情与证据整理成一张可打印的图：时间轴、法律关系图、证据矩阵、争点对照。

## 什么时候用

- 用户说「画时间轴」「诉讼可视化」「理一下法律关系」「做证据矩阵」「争点对照」；
- 庭前梳理、客户汇报、团队讨论需要一张图讲清案件。

## 怎么用

1. 先把材料结构化成 JSON（schema 见 `深鲸法律技能集` 的 `legal-litigation-viz`）；
2. 打开侧栏「法律·诉讼可视化」面板，把 JSON 粘进去；
3. 点「生成预览」看效果，点「保存 HTML」落到 `~/Desktop/诉讼可视化/`。

也可以命令行：

```bash
dsh-legal-viz case.json -o 案件-诉讼可视化.html
```

## 边界

- 只画用户给的事实；缺的进「证据缺口」，不脑补；
- 输出是梳理图，不构成法律意见，提交前须核对原始材料。
