# 诉讼可视化（DSH 插件）

把案情与证据整理成一张可打印的图：时间轴、法律关系图、证据矩阵、争点对照。

## 什么时候用

- 用户说「画时间轴」「诉讼可视化」「理一下法律关系」「做证据矩阵」「争点对照」；
- 庭前梳理、客户汇报、团队讨论需要一张图讲清案件。

## 怎么用（律师不需要接触 JSON）

面板三步（侧栏「法律·诉讼可视化」）：

1. **导入材料**：点「从本地文件导入」，选合同 / 往来函件 / 判决书 / 微信导出 / 转账记录（docx / pdf / md / txt / 图片 OCR）；面板自动抽取候选事件与证据，逐条核对采纳；没有材料的直接在表单里手填「+ 添加事件」，或用「表格导入」贴 Excel 里整理好的行列；
2. **核对要点**：时间轴顺序、当事人与关系、证据对应到哪个事实——这就是律师要做的全部确认工作；
3. **生成预览 → 导出**：默认导出 PNG / 打印 PDF（交付物）；SVG 给需要继续编辑的人；「JSON（存档/再编辑）」是高级选项，供下次改图复用，平时不用管。

AI 协作模式：把案情文字直接发给 AI，由 AI 按技能 schema 整理数据并在面板预览——律师只核对要点表，永远不需要自己写或理解 JSON。

命令行（可选，AI 使用）：`dsh-legal-viz case.json -o 案件-诉讼可视化.html`

## 边界

- 只画用户给的事实；缺的进「证据缺口」，不脑补；
- 每个事件可记来源（文件 / 页码 / 引文），生成后按 A4 打印核对原始材料；
- 输出是梳理图，不构成法律意见；AI 辅助生成，需承办律师复核。
